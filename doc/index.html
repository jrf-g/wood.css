About Wood.CSS

Wood.CSS is a simple CSS framework for creating wood-themed websites.

Dependencies

  • Google Fonts

Supported Elements

  • Headers
    • Level 1
  • Paragraphs
  • Buttons

Usage

To use Wood.CSS, simply include the CSS file in your HTML document and apply the "wood" class to your elements.

Features

  • Lightweight wood type Western fonts
  • Clean wood-themed colors
